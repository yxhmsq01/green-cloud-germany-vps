这些限制写在官方条款和页面角落里，评测文章很少展开，但每一条都可能影响你的决定。

**第一，特价款不退款，退款只有一次机会。** 绿云的 7 天退款政策只覆盖新客户的首台 VPS，且明确排除“特别折扣套餐”（Special discounted plans）。三个推论值得写明白：月付常规款在退款保护范围内；年付 Sale 款买之前就要想好，付了不退；退款资格只有新客户首台机器这一次，月付认证完线路后，再买特价款就是另一台不受保护的机器了。想试线路，先买月付，这个顺序不能反。
